Cinevoice

Your Independent AI Cinematic Companion

How to Use the App

1. Managing API Keys and AI Providers

You can use Grok, Gemini, OpenAI, and Mistral. If you don't have keys right now, you can skip the startup dialog and just use the app as an accessible video player.

Press Ctrl+M at any time to open a popup menu where you can instantly switch between models, or add a key for a new provider.

2. Basic Media Controls

Press Ctrl+O to open a file browser and select your video. Use Spacebar to pause and play. Use the Left/Right Arrow Keys to seek by 10 seconds, or Ctrl+Left/Right for a bigger 60-second jump. Press Home to return to the beginning, and a number key 0-9 to jump straight to that tenth of the video. Page Up/Page Down (without Ctrl) move to the previous or next video file in the same folder.

3. Commands Menu

Forget a shortcut? Press Ctrl+Down Arrow to open the Commands Menu. You can navigate the list with your arrow keys and press Enter or Escape to run the command you selected!

4. Describing What's Happening

Press any of F1-F6 or F9-F12 to instantly ask for one of ten built-in description styles, from a brief one-line description to a full cinematic narration of several frames (see the Preset Prompts table below for exactly what each key does). Ctrl+A lets you type your own custom question instead, and Ctrl+Shift+A lets you ask by speaking into your microphone. These two answer the question you actually asked — ask "what color is the car?" and you get the color, not a description of the scene — and they remember your last question, frame count and reply length between runs. Ctrl+Up Arrow repeats whichever prompt you last used.

You can save your own two favorite custom prompts: type one with Ctrl+A, then instead of pressing Enter, press Shift+F7 or Shift+F8 to save it to that slot. Afterwards, pressing plain F7 or F8 instantly reruns it. Like Ctrl+A, a saved prompt is answered on its own terms, so a slot holding a question gets an answer rather than a description.

For continuous narration, Ctrl+D describes the video automatically in 30-second chunks as you watch, in the manner of audio description: each chunk covers the thirty seconds about to play and reports only what is new, so a person, place or object already introduced is not described to you again. Ctrl+F toggles an auto-describe mode that re-describes the changing scene every 5 seconds. Ctrl+Shift+D pre-generates narration for the entire video in the background so playback never has to pause and wait; if this video already has saved block descriptions, a dialog first asks whether to regenerate everything from scratch, use what's already saved (which just turns on the same continuous narration as Ctrl+D), or cancel. Shift+F12 generates one single story covering the whole video from start to finish (and Ctrl+Shift+F12 regenerates it if you already have one cached).

Use Ctrl+F1 through Ctrl+F12 to choose the narration style (see the Narration Styles table below), and Ctrl+Page Up/Page Down to make descriptions longer or shorter. Your chosen style is remembered, so the next time you open Cinevoice it is still the one in use. The style colors the wording of everything the app says — descriptions, continuous narration and the answers to your questions alike — without changing what gets reported.

5. Offline AI Models (No Internet or API Key Needed)

The player can also describe scenes completely offline using AI models that run on your own computer. Press Ctrl+S to open Settings; the "Offline AI Model" list is the first thing in that dialog. Choose a model and activate the button below it to download it; download progress is announced every one percent and shown in the window title, and you can cancel and resume it later. Models are between about 1.9 and 5.5 gigabytes; smaller models are faster, larger models describe better. The "Uncensored" variants are less restrictive about what they will describe.

Once a model is downloaded, selecting it again in that same list changes the button to "Delete Selected Offline Model," which permanently removes it from your disk after a confirmation dialog that you can review in full with Tab.

Important: Once downloaded, an offline model appears in the model menu (Ctrl+M). Offline models run on your processor (or an Intel graphics chip when available) and are much slower than online models — expect many seconds up to minutes for a single description. They are not suitable for continuous video narration; use them for single frame descriptions when you have no internet connection or want full privacy. Loading a model into memory the first time also takes a while, and the larger models need 8 gigabytes of free memory or more.
