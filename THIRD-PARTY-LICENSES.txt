3. REMOVED DEPENDENCY: GPL-LICENSED FFMPEG (IMPORTANT HISTORY NOTE)
------------------------------------------------------------------------
An earlier version of this app used the moviepy library (MIT license) for
extracting audio from video files for a "Translate Audio Segment" feature.
moviepy depends on imageio-ffmpeg, which bundles a prebuilt ffmpeg.exe binary
from gyan.dev configured with --enable-gpl --enable-version3 and GPL-only
encoders (libx264, libx265) -- i.e. a GPLv3-licensed executable.

Distributing that binary would have required either (a) supplying FFmpeg's
GPL license text and a written offer of its corresponding source code, or
(b) replacing it with an LGPL-only FFmpeg build. To keep this application's
own licensing simple and avoid any GPL obligations entirely, the audio
transcription/translation feature (and moviepy/imageio/imageio-ffmpeg/
Pillow) has been removed from the app. The "Ask Voice Question" feature is
unaffected, since it captures microphone audio directly (via PyAudio) and
never touches ffmpeg.

As a result, this application no longer bundles, links to, or distributes
any GPL-licensed component.


4. AI MODELS DOWNLOADED AT RUNTIME (NOT PART OF THE INSTALLER)
--------------------------------------------------------------------
The offline description feature lets the user optionally download
pre-converted vision-language AI models directly from Hugging Face into
their own user profile folder (%LOCALAPPDATA%\Cinevoice\models). These
model weights are fetched by the user's own action, at their own risk, are
never bundled inside the installer/exe, and are not modified or
redistributed by this application -- the app only downloads and runs them
locally.

  - Qwen3-VL and Qwen2.5-VL-7B (official "OpenVINO" org conversions):
    Apache License 2.0, same as the upstream Qwen models from Alibaba Cloud.

  - "Uncensored" / abliterated community variants (from the "EZCon"
    Hugging Face account, derived from huihui-ai's abliterated Qwen3-VL
    fine-tunes): these are derivative works of the Apache-2.0-licensed Qwen3
    -VL base models. The uploader's repository pages do not always restate
    an explicit license tag, but as derivatives of an Apache-2.0 work they
    remain governed by Apache-2.0 terms absent any stated restriction.
    Users should independently review each model's Hugging Face model card
    before relying on it for anything beyond personal/experimental use.
